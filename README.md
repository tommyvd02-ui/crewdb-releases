# CrewDB

CrewDB is a Mac app for running a student film set as the 1st AD: crew,
schedules, call sheets, locations, budgets and gear, all in one place. Your
data stays on your Mac. It was built by Tommy Van Dyke for his own
productions and is shared with classmates in his film program.

This repository only hosts the downloads and automatic updates. The source
code isn't here.

## Download

**[Download CrewDB for Apple silicon Macs](https://github.com/tommyvd02-ui/crewdb-releases/releases/latest/download/CrewDB_AppleSilicon.dmg)**

Requires a Mac with Apple silicon (M1 or newer) and macOS 13 Ventura or later.
This link always points to the newest version.

## Install

1. Open the downloaded **CrewDB_AppleSilicon.dmg**.
2. Drag **CrewDB** onto **Applications**.
3. Open CrewDB from Applications, then click **Open** when macOS asks.

Always run CrewDB from Applications, not from the disk image or Downloads,
so it can update itself. When a new version is out, CrewDB shows
**Restart to update**.

The full guide covers the first launch, where your data lives, backups, the
optional Google features, and how to report a bug: **[INSTALL.md](INSTALL.md)**.
